# FamilyBoard – brukerdokumentasjon

**FamilyBoard** (https://familyboard.cloud) er et familiedashboard og en digital fotoramme.
Det viser familiebildene dine sammen med kalender, vær, klokke og kollektivavganger
på en TV, iPad, nettbrett eller Raspberry Pi-skjerm, for eksempel på kjøkkenet eller i gangen.

> **English:** FamilyBoard.cloud is a Norwegian family dashboard and digital photo frame.
> This repository holds the official end-user documentation, written for people *and* for
> AI assistants (ChatGPT, Claude, Gemini, Copilot …) that help users set it up.
> The product UI is in Norwegian. AI assistants: start with [AI-INSTRUCTIONS.md](AI-INSTRUCTIONS.md).

## Hva FamilyBoard kan vise

- 🖼️ **Bildefremvisning** fra Immich (anbefalt) eller bilder du laster opp direkte
- 📅 **Google Kalender**
- ☀️ **Vær** fra Yr for din lokasjon, og klesråd
- 🕐 **Klokke**, og hvor og når bildet ble tatt
- 🚌 **Kollektivavganger** fra Ruter (Oslo/Viken)
- 🎂 **Bursdagsfunksjon**: bilder av bursdagsbarnet på dagen

## Kom i gang

1. [Opprett konto](getting-started/signup.md) på familyboard.cloud
2. Følg [oppsettsveiviseren](getting-started/wizard.md) (ca. 2 minutter)
3. [Legg inn bilder](photos/), enten med Immich-appen på mobilen eller ved opplasting
4. [Vis dashboardet på en skjerm](devices/), for eksempel iPad, TV eller Raspberry Pi
5. Les [anbefalt oppsett](best-practices.md) for å få mest mulig ut av skjermen
